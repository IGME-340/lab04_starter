# Lab 04 Starter: GIF Finder

Starter code for **Lab 04: GIF Finder** in IGME-340.

**Lab instructions:** [labs/lab-04-gif-finder.md](https://github.com/jptweb/IGME-340-Shared/blob/main/labs/lab-04-gif-finder.md)

## Getting it

- **Download ZIP** (Code → Download ZIP), or
- **Use this template** to make your own copy on GitHub. Set it to **Private**, since your GIPHY API key will be in the code.

## Opening it

Open the folder that **contains `pubspec.yaml`** in VS Code. If you open the folder above it, Flutter
can't find the project, and the error you get won't say that.

Run it. You should see a purple app bar that says **GIF Finder** and an empty screen.

## Already set up for you

- The `http` package is already installed.
- The macOS network permission is turned on, so the app can reach GIPHY if you run it as a Mac desktop app.

In Project 2 you start your own project, so you'll do both of these yourself. `flutter pub add http`
is from Week 7B, and the macOS permission is the bonus section in the Week 8B notes.

## Submitting

Same as every other lab: `flutter clean`, zip it, upload to the MyCourses dropbox. Details are at the
end of the lab instructions.
